## Tech Stack

### Backend
- **Languages**: Java, PHP, Javascript, Python
- **Frameworks**: Spring Boot, Spring MVC, Spring Security, Spring Data JPA, Hibernate, Laravel  
- **API Design**: RESTful & Versioned APIs, Webhooks  
- **Security**: OAuth2, JWT, JWK, Certificate-based Authentication, Digital Signatures  
- **Access Control**: Rate Limiting, Request Signing, State Validation, Audit Logging  
- **Data Access**: JPA/Hibernate, Eloquent ORM, Transaction Management  
- **Async & Background Processing**:  
  - Jobs & Queues (Redis, Database)  
  - Spring Batch, Asynchronous Workflows  
- **Real-Time**: WebSockets, Server-Sent Events (SSE)  
- **Caching**: Redis, In-Memory, Database, Cache-First Patterns  
- **Testing & Migrations**: Liquibase, JUnit, Pest, TDD  

### Frontend
- **Frameworks**: React, React Router  
- **State Management**: Redux, Redux Toolkit, Zustand  
- **Styling**: Tailwind CSS, Bootstrap, Bulma  
- **Core**: Vanilla JavaScript, Responsive UI Development  

### Databases
- **Relational**: MySQL, PostgreSQL  
- **In-Memory / Messaging**: Redis  
- **Concepts**: SQL, Indexing, Query Optimization  

### DevOps & Infrastructure
- **Containerization**: Docker, Docker Compose  
- **CI/CD**: GitHub Actions  
- **OS & Runtime**: Linux  
- **Monitoring & Logging**: ELK Stack, Sentry, Prometheus, Grafana  

### Tooling & Practices
- **Version Control**: Git (GitHub, GitLab)  
- **API Docs**: Swagger / OpenAPI  
- **Architecture**: Modular Architecture, Dependency Injection (IoC), SOLID  
- **Performance**: Profiling, Load Testing  
- **Workflow**: Agile, Code Reviews
